# 交通費申報表

每月交通費 claim 工具：港鐵站到站成人八達通票價自動計算（MTR Open Data），巴士手動輸入金額。

## 功能

- 月份選擇，自動生成 28–31 日表格，週六日淺黃底
- 每日行程：第一程、第二程……可逐日無限加程（＋ 加一程）
- 每程先選「港鐵 / 巴士」：
  - 港鐵：起點、終點用下拉選站（按綫分組），自動計成人八達通票價
  - 巴士：路線（選填）+ 手動輸入金額
- 常用行程：設定一次，套用到全部日子或只套用到工作日
- 本月合計、港鐵小計、巴士小計、有申報日數
- 資料只存喺瀏覽器 localStorage，唔會上傳去伺服器
- 列印 / 存為 PDF：橫向 A4，autofit，連簽署欄
- 匯出 CSV（Excel 友善，UTF-8 BOM）

## 即刻試

解壓後雙擊 `index.html` 就開到，唔使 server。

## 上 Render（免費 Static Site）

1. 將呢個資料夾 push 去 GitHub repo
2. Render → New → Static Site → 揀呢個 repo
3. Publish Directory 留空（即係 `.`），Build Command 留空
4. Deploy，之後每次 push 去 main 就自動重新部署

## 注意

- 港鐵票價來源：港鐵 Open Data `mtr_lines_fares.csv`（2026-10-26 下載），僅供參考，申報前請自行核對
- 機場快綫、輕鐵不在此表內，如需申報請用「巴士」欄手動輸入金額

## REC 工程行程驗證 (`schedule-app/`)

- 保留 `rec-schedule-v1` localStorage 格式及原有頁面；載入舊資料不會改寫或刪除內容。
- 港鐵未選車站、無法識別車站、查無票價及無效票價會顯示原因，不會當成 $0。步行、公司車、票價資料中的真實 $0、自訂明確輸入 `0` 均有效；同站行程亦以票價表為準，不會自行假設免費。
- 自訂車費必須填寫非負十進制數字，最多兩位小數；不接受部分數字、科學記號、NaN、Infinity 或負數。工作時數可留白（零），每欄、每段及全日最多 24 小時，最多兩位小數。多段時數按實際工作累加，不可重複計算同一時段。
- 每日及每月未完整的合計顯示「待修正」。每日抽屜仍顯示「八達通成人」小計，月總車費則包括自訂車費；Excel 分別列出港鐵及自訂小計。
- 兩份 Excel 使用相同的整月驗證；錯誤訊息列明日期、行程及原因，有錯不會下載任何報表。金額與時數以百分之一單位累加，並檢查安全數值範圍。

測試（Node.js 22+）：

```sh
npm install
npm test
```

測試使用現有票價資料、jsdom 執行實際頁面內的測試數據產生器（固定隨機種子），以及附帶的 SheetJS 實際寫入／讀回 XLSX，涵蓋錯誤資料、免費行程、自訂零元、每日／月總計、兩份報表逐行對應及 localStorage 不變性。GitHub Actions 亦會執行。
